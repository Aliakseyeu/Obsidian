[[MySql]]

Данный запрос может помочь понять на сколько комфортно данные выборки помещаются на страницу и можно ли добавлять новый столбец или лучше создать новую таблицу

```mysql
SELECT
    TABLE_NAME,
    TABLE_ROWS,
    AVG_ROW_LENGTH,
    DATA_LENGTH,
    INDEX_LENGTH,
    ROUND(DATA_LENGTH / NULLIF(TABLE_ROWS, 0)) AS avg_data_per_row_calc,
    ROUND(8126 - AVG_ROW_LENGTH) AS headroom_bytes,
    ROUND(AVG_ROW_LENGTH / 8126 * 100, 1) AS pct_of_limit
FROM information_schema.TABLES
WHERE TABLE_SCHEMA = 'ваша_база'
  AND TABLE_NAME = 'ваша_таблица';
```

**Что смотреть:** `headroom_bytes` — сколько ещё можно «нарастить» строку до лимита. `pct_of_limit` — насколько таблица уже заполнена. Если `AVG_ROW_LENGTH` уже близок к 8000, любой новый столбец рискует вытолкнуть часть данных в off-page.[](https://www.baeldung.com/sql/mysql-determine-table-size#1)

> ⚠️ **Важно:** `AVG_ROW_LENGTH` не учитывает BLOB/TEXT полностью (они могут храниться вне страницы), поэтому для таблиц с такими полями реальная картина может отличаться.
