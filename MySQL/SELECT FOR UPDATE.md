[[MySql]]
[[TRANSCTION]]
[[SELECT FOR SHARE]]

```sql
BEGIN;

SELECT * FROM clients
WHERE id = 1
FOR UPDATE;
```

В данной выборке используется конструкция эксклюзивной блокировки FOR UPDATE. То есть если одна транзакция выбрала строку, то другие транзакции не смогут ее даже прочитать, пока не завершится текущая транзакция. После чего строку прочитает следующая транзакция. Если не использовать конструкцию FOR UPDATE, то прочитать строку можно, но изменить всё равно нельзя до тех пор пока не завершатся все транзакции блокирующие строку. Если в первой транзакции использовать конструкцию FOR UPDATE, а во второй нет. То третья транзакция сможет без проблем изменять запись после завершения первой транзакции независимо от того завершилась ли вторая. Потому что вторая транзакция не получила эксклюзивной блокировку на запись
