[[SELECT FOR UPDATE]]

```sql
BEGIN;

SELECT * FROM clients
WHERE id = 1
FOR SHARE;
```

В данной выборке используется конструкция разделяемой блокировки FOR SHARE. То есть разные транзакции разделяют между собой блокировку на текущую запись. Все транзакции могут прочитать строку, но ни одна из них не сможет изменить ее, пока не завершатся все транзакции блокирующие строку. Обновить ее не получится даже при вызове UPDATE без транзакции. Если в первой транзакции использовать конструкцию FOR SHARE, а во второй нет. То третья транзакция сможет без проблем изменять запись после завершения первой транзакции независимо от того завершилась ли вторая. Потому что вторая транзакция не получила разделяемую блокировку на запись
