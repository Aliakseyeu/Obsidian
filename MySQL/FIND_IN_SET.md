[[MySql]]

FIND_IN_SET() — это **функция MySQL**, которая ищет значение внутри **строки, разделённой запятыми**.

Используется, когда в столбце лежит что-то вроде "3,7,12,15" и нужно проверить, есть ли там, например, `7`.

---

# ✅ Синтаксис

`FIND_IN_SET(needle, haystack)`
- **needle** — что ищем
- **haystack** — строка со значениями, разделённая запятыми

Возвращает:
- номер позиции найденного элемента (1,2,3…)
- **0** если не найден
- **NULL**, если haystack = NULL

---

# 📌 Пример

`SELECT FIND_IN_SET('7', '3,7,12,15');`

Результат: `2`

---

# 📌 Использование в WHERE

`SELECT * FROM users WHERE FIND_IN_SET(3, role_ids);`

Если `role_ids = '1,3,5'`, строка попадёт в выборку.

---

# 📌 Поиск нескольких значений

Если нужно найти записи, где поле содержит **хотя бы одно** из значений:

`WHERE FIND_IN_SET(3, role_ids) OR FIND_IN_SET(7, role_ids)`
