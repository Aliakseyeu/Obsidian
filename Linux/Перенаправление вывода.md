#bash 

```bash
command >/dev/null 2>&1
```

\>/dev/null - перенаправляет стандартный вывод в пустоту

### Что значит `2>&1`
Расшифровка пошагово:
- `2` — это поток **ошибок (stderr)**    
- `>` — перенаправление вывода    
- `&1` — "направить туда же, куда сейчас направлен поток **1** (stdout)"    

👉 То есть:

> «Отправь ошибки (`stderr`) туда же, куда уже отправляется обычный вывод (`stdout`)».

| Команда                   | Что делает                                                     | Что **остаётся видимым**                     |
| ------------------------- | -------------------------------------------------------------- | -------------------------------------------- |
| `command >/dev/null`      | Отправляет **только стандартный вывод (stdout)** в `/dev/null` | Ошибки (stderr) всё ещё выводятся в терминал |
| `command >/dev/null 2>&1` | Отправляет **и stdout, и stderr** в `/dev/null`                | Ничего не выводится вообще                   |

|№|Поток|Название|Назначение|По умолчанию|
|---|---|---|---|---|
|0|`stdin`|стандартный ввод|ввод данных в программу|клавиатура|
|1|`stdout`|стандартный вывод|нормальный вывод программы|экран|
|2|`stderr`|стандартный поток ошибок|сообщения об ошибках|экран|
