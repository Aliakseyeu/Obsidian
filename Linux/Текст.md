
Переписать все содержимое файла

```bash
echo "text" > filename.txt
```

---

Дописать в конец файла

```bash
echo "text" >> filename.txt
```

---

Дописать в начало файла

```bash
echo "Новая строка" | cat - filename.txt > temp && mv temp filename.txt
```

```bash
sed -i '1i Новая строка' filename.txt
```

---

Вывести все содержимое файла

```bash
cat filename.txt
```

---

Вывести первые 10 строк или 5

```bash
head filename.txt
head -n 5 filename.txt
```

---

Вывести последние 10 строк или 5

```bash
tail filename.txt
tail -n 5 filename.txt
```

---

Вывести начало и конец

```bash
(head -n 5 filename.txt; echo "..."; tail -n 5 filename.txt)
```

---

Заменить часть текста

Найти строку с нужным текстом:
```bash
grep -n 'pattern' file.txt 
```

Заменить текст в строке 3 на new text
```bash
sed -i '3c\new text' file.txt 
```
- -i - заменяет содержимое, без этого ключа будет вывод изменения в консоль, но сам файл останется без изменений
- 3 - номер строки
- c\ - заменить
- new text - новый текст
- -i.bak - создаст копию file.txt.bak до изменения

Если нужно добавить текст с аналогичными кавычками

```bash
sed -i '3c\new '\''super'\''  text' file.txt
```

---

Сравнить текст файлов

```
diff first.txt second.txt
```

Выведет разницу. Если ничего не выведет, значит файлы идентичны
