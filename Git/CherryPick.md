Команда копирует коммиты из другой ветки
Хэш коммита можно получить командой `git log`

```bash
git checkout target-branch

git cherry-pick commit_hash
```

Можно скопировать несколько 

```bash
git cherry-pick abc1234 def5678
```

Или скопировать диапазон

```bash
git cherry-pick abc1234^..def5678
```
спользование `^` в диапазоне — это трюк, чтобы сделать диапазон **инклюзивным** с левой стороны. По умолчанию коммит указанный слева не включается в диапазон. Крышка указывает на то что его нужно включить в диапазон
